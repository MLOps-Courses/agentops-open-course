{{- /* Overrides Hextra's Mermaid render hook for one reason: the theme names every diagram "Diagram", so a screen reader announces fifty-five identical images and the accessibility smoke's label assertion could not fail. `role="img"` makes the SVG subtree presentational, so this label is the entire name a screen-reader user gets. It is derived from the `**Diagram in words:**` sentence that follows this fence, which every diagram carries because tools/internal/conventions requires it — so the name is the author's own description of this diagram rather than a number, and no two diagrams on a page share one. The markdown stripping is what a name needs and a paragraph does not: shortcodes, link targets, inline HTML, and code ticks all read aloud as noise. A fence may still override the derivation with a block attribute, which Goldmark exposes here because hugo.toml enables markup.goldmark.parser.attribute.block: ```mermaid {ariaLabel="The kagent reconcile loop"} The page title is the last resort, for a diagram whose prose cannot be located. checkRenderedDiagramNames fails the build when two diagrams on one page still share a name, which is what keeps the derivation honest. */ -}} {{- $prose := "" -}} {{- with .Inner -}} {{- $parts := split $.Page.RawContent . -}} {{- if eq 2 (len $parts) -}} {{- with findRE `\*\*Diagram in words:\*\*[^\n]*` (index $parts 1) 1 -}} {{- $prose = index . 0 -}} {{- end -}} {{- end -}} {{- end -}} {{- $derived := "" -}} {{- with $prose -}} {{- $name := replaceRE `\{\{[%<][^}]*[%>]\}\}` " " . -}} {{- $name = replaceRE `\[([^\]]*)\]\([^)]*\)` "$1" $name -}} {{- $name = replaceRE `<[^>]*>` " " $name -}} {{- $name = replaceRE "[`*]" "" $name -}} {{- $name = replaceRE `\s+` " " $name | strings.TrimPrefix "Diagram in words: " | strings.TrimSpace -}} {{- /* Keep the opening sentence when there is one. The lowercase pair before the full stop is what stops an enumerated "0. Overview" from ending it early. */ -}} {{- $derived = replaceRE `^(.{15,}?[a-z]{2})\. .*$` "$1." $name | truncate 150 -}} {{- end -}} {{- $label := .Attributes.arialabel | default .Attributes.ariaLabel | default $derived | default (printf "Diagram on %s" .Page.Title) -}} {{- with $label -}}

{{- end -}} {{- .Page.Store.Set "hasMermaid" true -}}
